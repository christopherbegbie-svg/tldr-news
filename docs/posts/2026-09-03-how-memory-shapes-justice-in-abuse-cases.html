How Memory Shapes Justice in Abuse Cases

Understanding why repeated trauma creates different memories

  • Single events create detailed, specific memories
  • Repeated events (like abuse) create pattern-based memories instead
  • Abuse survivors may not recall exact dates or details—but still be truthful
  • This research is changing how courts understand witness testimony
  • Helen Paterson's work won a prestigious Australian Eureka Prize for this discovery
